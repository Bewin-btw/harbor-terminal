# Harbor

[English](README.md) · Русский

Локальное приложение для macOS: терминальные сессии в боковом списке, как чаты.

## Запуск

Открой `~/Applications/Harbor.app`. Нажми **Новая сессия** и выбери Терминал, Claude, Codex или SSH. Для каждого проекта можно выбрать рабочую папку и задать название.

- `⌘N` — новая сессия.
- `⌘K` — поиск по сессиям.
- `⌘O` — импорт сохранённого диалога Claude/Codex.
- `⌘F` — поиск в выводе терминала; `⇧⌘F` — поиск сразу по всем сессиям.
- `⌘T` — терминал в папке текущей сессии; `⌘D` — то же самое справа, в разделённом экране.
- `⌘1` … `⌘9` — переключение по списку.
- `⌘⌥↑` / `⌘⌥↓` — предыдущая/следующая сессия.
- `⌘+`, `⌘-`, `⌘0` — размер шрифта.
- `⌘C` / `⌘V` — копирование/вставка; `Ctrl+C` отправляется программе.
- Правый клик по сессии — переименование, закрепление, «Открыть справа», команда при запуске, завершение и архив.
- Кнопка **по проектам** над списком группирует сессии по git-репозиторию (или папке); группы сворачиваются. На карточке видна текущая ветка.
- Файл, перетащенный в терминал, вставляется как путь с экранированием, как в Terminal.app.
- Когда агент закончил ответ или ждёт тебя, а окно не в фокусе, приходит уведомление macOS, а на иконке в Dock растёт счётчик.
- Перетаскивание карточки за маркер `⠿` — изменение порядка; перенос между группами меняет закрепление. На выделенной карточке работают `⌥↑` / `⌥↓`.
- **Оформление** внизу слева или в меню **Вид** — шесть тем, включая светлую Paper.
- Полоса справа — перетаскивание истории; на выделенной полосе работают Home / End, Page Up / Down и стрелки. В отдельном экране полноэкранной CLI доступность истории определяет сама программа.

Закрытие окна и `⌘Q` завершают только интерфейс. Отдельный менеджер продолжает обслуживать работающие терминалы. Приложение не добавляет себя в автозагрузку.

## Пауза, завершение и восстановление

**Пауза** останавливает локальное дерево процессов выбранной сессии. Память остаётся занятой. Сетевые операции могут истечь по таймауту; задачи на удалённом SSH-сервере продолжают работать. Если доступ к одному из процессов запрещён, Harbor отменяет сделанную часть приостановки. Уже остановленные самой оболочкой jobs сохраняют своё состояние.

**Сохранить вывод и завершить процесс** отправляет сигналы завершения локальным процессам. Не используй это посреди важной операции. Для агентов предпочтителен штатный выход из их CLI после завершения ответа. Архив доступен для завершённых сессий; он ничего не удаляет из истории Claude/Codex.

**Перезапуск приложения:** подключение к тем же живым PTY и процессам, включая состояние shell и переменные окружения.

**Перезагрузка Mac или потеря менеджера:** восстановление карточек, рабочих папок и последнего снимка вывода. Прежние процессы помечаются как прерванные. Произвольные команды не выполняются заново автоматически; исключение — «команда при запуске» терминала с явно включённым автозапуском. Остальное поднимается одной кнопкой **Возобновить прерванные**. Снимки сохраняются примерно раз в 2 секунды при изменении вывода, от 4000 до 20 000 строк на сессию (настраивается в «Оформлении»). При аварии последние несохранённые изменения могут потеряться.

**Claude:** новые диалоги запускаются с заранее известным `--session-id`; продолжение использует `claude --resume ID`. Пустой диалог может ещё не быть сохранён самим CLI.

**Codex:** через локальный `codex app-server` создаётся пустой постоянный thread, его ID записывается до запуска `codex resume ID --no-daemon`. Создание thread не отправляет пользовательское сообщение или запрос генерации. Отдельный runtime позволяет приостанавливать процессы именно этой сессии. Модель, авторизация и разрешения берутся из существующей конфигурации Codex.

**SSH:** используются OpenSSH, ключи и `~/.ssh/config`. Пустой порт означает настройки SSH, явный порт переопределяет их. Для продолжения удалённой задачи после разрыва связи запускай её в `tmux` на сервере и подключайся к нему снова.

**Импорт:** читает локальные метаданные Claude JSONL и Codex SQLite/JSONL, показывает последние сохранённые диалоги. Перед продолжением импортированного диалога заверши его старый экземпляр. Импорт не переносит память, процессы или незавершённые операции из Terminal.app. Обычные существующие окна Terminal.app остаются в нём.

## Статусы Claude и Codex

AI-сессии открываются в полноразмерном живом терминале. Собственные сообщения выделяются цветом текста и лёгким фоном прямо в строках терминала, без подписей. Для распознавания используются сохранённые пользовательские сообщения; меню и ответы не окрашиваются по одному лишь символу приглашения.

Правая полоса управляет обычным scrollback, а в полноэкранном Claude/Codex — родной историей CLI через события прокрутки и Ctrl+Home / Ctrl+End. Положение ползунка в этом режиме приблизительное: CLI не предоставляет точный размер внутренней истории. Большие движения колеса разбиваются на небольшие пакеты; дробные движения трекпада накапливаются. Ввод, подтверждения и процессы сохраняются в исходном терминале. Проверено на живом Claude Code 2.1.316; привязки клавиш CLI могут влиять на навигацию.

«Работает», «Требуется действие», «Ответ завершён» и «Ждёт сообщения» относятся к ответу агента. Завершённый ответ не останавливает процесс: с ним можно продолжать диалог. Пауза, сохранение и прерывание имеют приоритет.

Harbor раз в секунду читает локальные данные, не меняя настройки или историю CLI. Claude Code 2.1.316 сообщает `busy`, `waiting`, `idle` через собственный реестр сессий; завершение ответа уточняется по журналу. Для Codex CLI 0.166.0 используются события `task_started`, `task_complete`, `turn_aborted` и запросы `request_user_input` из JSONL. Диалог разрешения дополнительно распознаётся в текущем видимом экране, снимок которого обновляется примерно каждые 2 секунды. Подсказка у статуса показывает источник. Распознавание зависит от версии и языка CLI; неподдерживаемый источник отображается как «Сессия открыта», без выдуманного завершения по таймауту. Обычные shell/SSH показывают состояние процесса.

Тема и порядок карточек сохраняются в локальных настройках интерфейса внутри каталога Harbor. Цвета, которые CLI задаёт явно, остаются под её управлением.

## Данные

`~/Library/Application Support/Harbor/`:

- `sessions.json`, `sessions.json.backup` — карточки, настройки и ID диалогов.
- `screens/` — снимки терминалов.
- `manager.log` — диагностика фонового менеджера.

Каталог создаётся с правами `0700`, история с `0600`. Содержимое терминала может включать чувствительный вывод; файлы не шифруются приложением. Для открытия каталога есть пункт меню Harbor. Файлы истории Claude/Codex импортёр не изменяет.

Связь с менеджером идёт через локальный Unix-сокет с правами `0600`. Сетевого сервера у Harbor нет. Терминальные программы, включая AI CLI и SSH, используют сеть как обычно.

## Разработка

Требования: macOS 13+, Apple Silicon, Node.js 22.12+ для сборки, установленный Claude/Codex для соответствующих типов сессий. Проверено на macOS 15.6, Claude Code 2.1.316, Codex CLI 0.166.0. Новые сессии Codex требуют CLI с `app-server thread/start` и `--no-daemon`.

```sh
npm ci
npm test
npm run test:integration
npm run build:ui
node scripts/ui-smoke.cjs
node scripts/ui-native-terminal.cjs
npm start
npm run package
```

Интеграционные тесты требуют Python 3 и установленного Codex CLI: один тест создаёт пустой thread в отдельном CODEX_HOME. GUI-тестам нужна графическая сессия macOS; тест родного скролла использует /usr/bin/python3. Тесты запускают настоящие PTY и процессы в отдельных временных каталогах. GUI-тест проверяет ввод, переключение, поиск, закрепление, выход и повторный запуск приложения с сохранением PID и переменных shell.

Сборка: `release/Harbor-darwin-arm64/Harbor.app`. Для проверки упакованного приложения передай путь к его исполняемому файлу через `HARBOR_APP_PATH` в `scripts/ui-smoke.cjs`.

Сборка подписана локальной ad-hoc подписью, без Developer ID и notarization. Это ранняя версия для сборки из исходников; macOS может предупреждать о неизвестном разработчике.
